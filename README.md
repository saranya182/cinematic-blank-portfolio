# Cinematic Blank Portfolio

A generic responsive portfolio starter with a cinematic dark theme and red accents.

## Included
- Responsive navigation and mobile menu
- Hero, About, Projects, Skills and Contact sections
- Hover effects and responsive layouts
- Placeholder content only: no personal names, photos, resumes, contact details or real project information

## Preview locally
Open `index.html` in a browser, or use VS Code Live Server.

## Customize
Edit `index.html` to add your own content. Edit `style.css` to adjust colours, fonts and layout.

## Publish
Upload this folder to a GitHub repository and enable GitHub Pages, or import the folder into Vercel as a static site.

This is an independently created generic starter inspired by cinematic streaming-style portfolio layouts. It is not affiliated with Netflix or the original GitHub project.
