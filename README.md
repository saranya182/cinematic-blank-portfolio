# 🎬 Cinematic Blank Portfolio Template

A modern, cinematic portfolio website template inspired by streaming-platform-style interfaces.

This project was created as a learning and design exploration, focusing on creative layouts, smooth navigation and a visually engaging user experience.

## 🌟 Live Demo

[View Live Portfolio](https://saranya182.github.io/cinematic-blank-portfolio/)

## ✨ Features

- Cinematic black-and-red theme
- Modern hero section
- Responsive navigation bar
- About section
- Featured projects section
- Skills and expertise section
- Contact section
- Mobile-friendly design
- Interactive hover effects
- Smooth scrolling

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Git and GitHub
- GitHub Pages

## 📂 Project Structure

```text
cinematic-blank-portfolio/
│
├── index.html

```

## 🚀 Run Locally

1. Clone the repository:

```bash
git clone https://github.com/saranya182/cinematic-blank-portfolio.git
```

2. Open the project folder.
3. Open `index.html` in your browser or use VS Code Live Server.

## 🌐 Deployment

This website is hosted using GitHub Pages.
